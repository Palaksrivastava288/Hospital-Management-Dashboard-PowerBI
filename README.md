# Hospital-Management-Dashboard-PowerBI
# 🏥 Hospital Management Dashboard

## 📌 Project Overview
This project is an interactive Hospital Management Dashboard developed using **Power BI** and **PostgreSQL**. 
It provides insights into hospital operations, patient management, doctor performance, financial analysis, and prescriptions through interactive dashboards.

## 🛠️ Tech Stack
- Power BI
- PostgreSQL
- Power Query
- DAX
- Data Modeling

## 📊 Dashboard Pages
- 🏠 Home
- 📈 Executive Summary
- 👨‍⚕️ Patient Analysis
- 💰 Financial Dashboard
- 🩺 Doctor Performance

## 📌 Key KPIs
- Total Patients
- Total Doctors
- Total Appointments
- Total Prescriptions
- Total Revenue
- Inventory Value
- Average Experience

## 📈 Features
- Interactive slicers
- KPI Cards
- Revenue Analysis
- Patient Analysis
- Doctor Performance Analysis
- Prescription Analysis
- Financial Insights
  
## 🗄️ Database
The data is stored and managed using PostgreSQL and connected to Power BI for reporting and visualization.

- SQL Queries
- Data Cleaning
- Data Modeling
- DAX Measures
- Dashboard Design
- Business Intelligence
- Data Visualization
